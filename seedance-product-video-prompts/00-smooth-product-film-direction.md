# Verdent Smooth Product Film Direction

Goal: make each episode feel like a premium animated product commercial, not a feature explainer, not a screen recording, and not a tutorial.

Series name:
One Sentence. One Outcome.

Core idea:
A user's sentence enters Verdent. Verdent turns it into structured motion, organized work, and a finished outcome.

## What The Video Should Feel Like

- Smooth product launch film
- Calm, premium, precise
- One continuous flow from input to outcome
- UI objects transform into the next scene instead of hard cutting
- The viewer should understand the result even without reading text
- Product capability is shown through movement, not through explanation

## Visual Constitution

- Pure white background
- One Verdent deep green: #144835
- Rounded white cards
- Soft long shadows
- Gray placeholder text bars only
- Real captions, feature names, product labels, and logo are added in post
- No humans
- No hardware
- No fake third-party logos
- No sci-fi dashboard
- No terminal walls
- No random generated words
- No clutter

## Motion Constitution

The motion should be extremely smooth and continuous:

- Input bubble stretches into Manager card
- Manager card pulses once, not repeatedly
- Cards split, glide, stack, dock, and snap into place
- Lines should draw themselves gently between related objects
- Checkmarks should arrive as soft completion beats
- Result card should feel heavier and more final than process cards
- Camera should use slow push-ins, slight parallax, and elegant reframing
- Avoid fast chaotic motion, spinning, flashing, shaking, or busy effects

## Shared Episode Structure

A. Input

- One centered chat input or speech bubble
- User sentence represented mostly by gray text bars
- Real sentence added in post
- The input bubble should feel empty, then purposeful

B. Activation

- A deep green Manager card rises or expands from the input
- One soft pulse
- Surrounding UI becomes organized around it
- This is the series memory point

C. Execution

- The only episode-specific section
- Must show the feature through object choreography
- Use only cards, chips, columns, checkmarks, toggles, progress rings, timelines, charts, document pages, previews, and connecting lines
- No explanatory paragraphs

D. Delivery

- Green checkmark
- Result card
- Live-ready or export-ready feeling
- The result should be visually obvious: app preview, deck, report, chart, image, video card, dashboard

E. End Frame

- Clean white or very soft sage frame
- Leave space for post-produced text and Verdent logo
- End card should be reused across the series

## Prompt Writing Rule

Do not ask the AI video model to create exact text.

Bad:
Type "Launch a new landing page by Friday" into the input.

Better:
Show a chat input with 2-3 gray placeholder text bars. Leave room for post-production overlay of the sentence.

Bad:
Show GitHub, Stripe, Supabase, Notion, and Linear logos.

Better:
Show generic tool integration chips with abstract icons only, no readable brand names.

## Recommended Master Prompt Prefix

Create a premium vertical 9:16 animated product commercial for Verdent, around 24 seconds.

This is a fully animated product film, not a screen recording, not a tutorial, and not a feature list.

Use a pure white background, one deep Verdent green accent color (#144835), rounded white UI cards, soft long shadows, gray placeholder text bars, minimal abstract icons, and very smooth product motion.

All real text, captions, feature names, and the Verdent logo will be added later in post-production. Do not generate readable UI copy, fake logos, or random text. Use gray bars for text areas.

No humans, no devices, no hardware, no terminal code, no sci-fi dashboard, no neon, no clutter.

The video should communicate through motion: one user sentence enters Verdent, a Manager card activates, the work becomes structured, the episode-specific workflow unfolds, and a finished result card lands.

Motion should be fluid and premium: cards morph, split, glide, dock, and snap into place; connecting lines draw softly; checkmarks appear as gentle completion beats; camera moves with slow push-ins and subtle parallax.

Leave the final two seconds clean for a reusable post-produced end card.

## Episode Priority

Build and test these first:

2. EP2 Create App: validates visible creation and live-preview payoff.
3. EP5 Data Analysis: validates analytical motion and visual variety.

Once these three feel right, batch the rest.
