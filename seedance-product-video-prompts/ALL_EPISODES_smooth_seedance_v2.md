# Verdent Seedance Prompts V2

Use these prompts for smooth product animation generation. For safer output, let Seedance create UI motion and gray placeholder text only. Add all real text, captions, feature names, and Verdent logo in post-production.

Common visual rule for every episode:

Pure white UI, one Verdent deep green accent (#144835), rounded white cards, soft long shadows, gray placeholder text bars, abstract icons only, no humans, no hardware, no fake logos, no real third-party logos, no terminal walls, no sci-fi dashboard, no clutter, no readable generated text.

Keep clean overlay-safe space at the top center and in the final two seconds. Do not let moving cards, lines, charts, or checkmarks pass through those text zones.

## EP1 · Manager

```text
Vertical 9:16, 24-second product animation for Verdent.

Create a smooth product commercial, not a screen recording and not a tutorial.

Opening feeling:
An empty AI chat feels scattered and unfinished. Several small gray message cards drift loosely, representing unfinished requests and unclear next steps. No readable text.

Then the scene cleans itself into a calm Verdent Manager workspace.

A single input bubble appears with gray placeholder bars. Leave clean space above it for post-production overlay of the user sentence:
"Launch a new landing page by Friday."

The input bubble compresses into a deep green Manager card. The card rises, pulses once, and becomes the control center of the scene.

The goal breaks into five unlabeled phase cards. Each phase card uses only a gray title bar and a simple abstract icon. The cards glide into a Kanban board with four columns. Column headers are gray bars only.

Several worker cards move in parallel through the board. Motion should feel organized and smooth, not chaotic. One review column catches cards before they enter the final completed area.

Subtle secondary chips appear around the Manager card, using abstract icons only: memory, tools, schedule. They connect with thin green lines, then fade back so the board remains the focus.

Final result:
The board resolves into a calm project dashboard. Show completed task cards, a review status area with gray bars, a live preview card, a URL-shaped bar, and one clear green checkmark.

End frame:
Clean white frame, soft green accent shape, empty logo/title space for post-production.

Visual style:
Premium product animation, clean white UI, Verdent green accents, soft shadows, editorial tech feel, readable empty spaces, cinematic but minimal, no realistic humans, no clutter, no sci-fi overload, no terminal wall.
```

Post overlay:

- Opening: Your AI chat is not a project manager.
- Input: Launch a new landing page by Friday.
- End: From one sentence to structured execution.
- Feature: Verdent Manager
