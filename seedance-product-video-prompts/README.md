# Verdent Product Video Prompts for Seedance

Series: One Sentence. One Outcome.

Use these as copy-ready prompts for AI video generation. Each episode is designed as a fully animated product marketing video, not a real screen recording and not a tutorial.

Production notes:

- Generate the animation without final brand logo text when possible.
- Add Verdent logo, episode title, and final caption in post-production.
- Keep the final 2 seconds visually clean so the same end card can be reused.
- Reject outputs with unreadable fake UI text, fake third-party logos, humans, devices, or cluttered sci-fi dashboards.
- Preferred format: vertical 9:16, 24 seconds.

Unified visual language:

- Clean white AI workspace
- Soft sage background panels
- Deep Verdent green accents
- Rounded white cards
- Soft long shadows
- Minimal UI labels
- Smooth camera moves
- Calm, premium, structured, product-led motion
