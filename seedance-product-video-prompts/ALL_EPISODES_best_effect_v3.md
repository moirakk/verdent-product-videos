# Verdent Product Film Prompts V3

These are copy-ready Seedance prompts optimized for smooth product-commercial animation. They are aligned to Verdent's official product framing as of September 14, 2026.

Key rule: ask Seedance to animate product flow, not to generate final copy. Use gray placeholder bars inside UI. Add the real Verdent logo and all exact text in post-production.

## Shared Prefix

Use this at the start of every Seedance prompt:

```text
Create a premium vertical 9:16 product commercial animation for Verdent, around 24 seconds.

This is a fully animated product film, not a real screen recording, not a tutorial, and not a feature list.

Visual style: pure white background, one deep Verdent green accent color (#144835), rounded white UI cards, soft long shadows, generous whitespace, minimal gray placeholder text bars, abstract line icons only, refined product motion, calm cinematic pacing.

Critical text rule: do not generate readable words, captions, labels, brand names, UI copy, or random text inside the animation. Use gray placeholder bars for all text areas. Exact titles, captions, product labels, and the Verdent logo will be added later in post-production.

Logo rule: the final frame must include a clean empty logo-safe area, but do not invent, redraw, distort, or spell the Verdent logo. The official Verdent logo will be composited later.

Layout safety rule: keep a clean caption-safe area in the upper center and a clean logo-safe area in the final two seconds. Do not let cards, icons, lines, charts, checkmarks, or decorative motion cross these areas.

Avoid: people, faces, hands, devices, hardware, fake third-party logos, readable text, misspelled text, terminal walls, code walls, busy dashboards, sci-fi HUDs, neon effects, clutter, shaky motion, fast chaotic cuts.

Motion style: extremely smooth. UI objects should morph, split, glide, dock, stack, and snap into place. Use one soft green pulse for activation, gentle line drawing, subtle parallax, slow camera push-ins, and one satisfying final alignment.
```

## EP1 · Manager

```text
[Shared Prefix]

Product truth:
Verdent Manager is an AI technical co-founder. The user describes an outcome in plain language; Manager plans the work, breaks it into executable subtasks, runs workers in parallel, routes completed work into review, remembers project preferences, and returns a clear result.

Opening composition, 0-3s:
Start with a wide, quiet white canvas. Several loose chat bubbles and unfinished task cards float apart with gray placeholder bars, suggesting an ordinary AI chat that does not manage the work. Keep the upper center clean for a post-production hook.

Transition, 3-6s:
The scattered cards gently pull toward the center. They compress into one deep green Manager card. The card rises forward, pulses once, and becomes the control center. A soft circular field expands behind it, then fades.

Execution, 6-18s:
The Manager card emits five clean phase cards. Do not label them with words; use gray bars and abstract icons. The phase cards unfold into a structured work surface: a four-column board with unlabeled column headers, several subtasks, and a dedicated review lane before completion.

Worker cards move in parallel, each following a smooth green path. Some cards pause in the review lane, receive a small green checkmark, then move into the completed area. Small secondary chips appear briefly around the board to represent memory, remote messaging, tools, and schedule. They should be subtle and should not become the main story.

Delivery, 18-22s:
The board compresses into a calm result handoff card: finished output area, files/changes area represented by gray rows, review status area, live preview rectangle, URL-shaped bar, one large green checkmark.

End frame, 22-24s:
Everything resolves to a clean white end frame with a soft green accent shape and empty space for the official Verdent logo and final caption.
```

Post overlay:
- Opening: Your AI chat is not a project manager.
- Input: Launch a new landing page by Friday.
- End: From one sentence to structured execution.
- Feature: Verdent Manager
