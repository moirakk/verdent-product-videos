# EP03: Design First

Visual references: Manager v009 and Create App v005. Portrait autoplay film, 32 seconds.

## Feature verification

Official reference checked on 2026-09-16:
https://www.verdent.ai/docs/verdent-manager/core-features/design-mode

Design Mode starts with a product brief, explores visual directions, plans screens for more complex products, builds from an approved direction, and allows preview and further iteration. It is not presented here as Figma import or guaranteed pixel-perfect conversion.

## Story

- 0-3s: A dimensional habit-tracker interface introduces the design-first idea.
- 3-6.5s: A calm habit tracker for busy people, entered as the brief.
- 6.5-10.5s: Editorial, Calm, and Bold visual interpretations unfold.
- 10.5-14s: Calm is selected; the chosen direction is explicitly approved.
- 14-18s: Typography, color, and spacing specimens reveal the choices behind Calm.
- 18-23s: The chosen visual language extends to Welcome, Today, and Progress; confirm the screen plan.
- 23-27s: The approved design assembles into the application.
- 27-29s: Hold on the same design in the application preview.
- 29-32s: Supplied Verdent logo and closing line.

The app, three direction names, screen plan, and design specimens are illustrative animation content. They are not a recording of a real Verdent run or a promise that every project receives exactly three alternatives. The specimens explain visual decisions; they do not depict a verified token-editor feature. No user data is stored and no backend deployment is implied.
