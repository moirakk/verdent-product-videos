## 六个候选重新判断

### 1. Create Image — 保留能力，重写故事

新增价值：为已有产品生成可用的图片素材文件。

与 EP03 的边界：EP03 决定应用界面怎么设计；本集从已确定的产品/品牌出发，只解决缺一张配图的问题。官网 Image Tool 本身也有方案比较和视觉对齐能力，与 Design Mode 确有交集；为系列去重，本集主动不以这些能力为主线。

建议案例：已有 wellness 应用的空状态缺一张插画，描述图像内容，生成图片，再将文件用于原有界面。结尾落在图片素材与使用位置，避免再从头构建整页网站。

不展示：三维模型生成、可编辑 3D 文件、渲染器参数、模型搭建。3D 是影片表现手法，不能成为虚构的产品功能。此前“立体结体逐渐生成”的试稿容易产生这个误解，放弃该主线。

官方：https://www.verdent.ai/docs/verdent-manager/core-features/image-tool

### 2. Generate Video — 保留

新增价值：生成带时间和动作的视频结果，区别于静态图片及应用预览。

建议案例：从一张已有产品图出发，描述镜头运动，等待生成，播放生成结果，再下载视频。

不展示：把我们自己写的 Three.js 旋转当作真实 AI 视频生成结果；虚构视频剪辑时间线；将生成耗时表现为即时完成。正式制作需要能代表结果的视频素材，清楚区分示意和真实输出。

官方：https://www.verdent.ai/docs/verdent-manager/core-features/video-generation

### 3. Publish — 保留，边界最清楚

新增价值：从只有自己在预览里看到，变成别人能通过链接访问。

建议案例：开场直接接一个已完成的 Cloud 应用，发布后在第二台设备打开同一链接。后续更新只作简短收束。

不展示：重复需求到应用的构建过程；把 local folder 描述成一键直接上传。当前文档明确 Cloud 项目和本地项目的差别。

官方：https://www.verdent.ai/docs/verdent-manager/core-features/cloud-projects-and-publishing

### 4. Automations — 保留

新增价值：同一项工作按约定时间重复运行，而不是每次手动重新要求。

建议案例：每周一 9 点汇总项目进展；重点是“设定一次—日期推进—下一次运行—状态与结果”，不把汇总报告内容再做成数据分析篇。

不展示：关机后仍执行、应用退出后仍执行、云端永久托管。官网说明需要 Verdent 应用保持活跃。

官方：https://www.verdent.ai/docs/verdent-manager/core-features/automation

### 5. Message Anywhere — 候补

确有新能力：通过已连接的 Telegram/Slack/飞书给 Manager 交任务。

重叠风险：如果大半集又在桌面上创建应用、拆解任务，就重复 EP01/EP02。核心变化只是委派入口和结果回到聊天渠道，信息量较少。更适合短功能片；先不硬凑成和前几集同长度的大流程。

仅在独立场景成立后再制作：离开电脑时发出具体请求，任务在项目中进行，结果回到原聊天。连接和配对是前提。

官方：https://www.verdent.ai/docs/verdent-manager/core-features/instant-messaging

### 6. Skills — 候补

确有新能力：可复用的知识与工作流程包，含指令、脚本或参考资料，按名称调用。

重叠风险：用“记住品牌/偏好”讲它，会撞 EP01 Memory；用“整套品牌素材保持一致”讲它，会撞图片篇。

只有讲清楚可复用的“流程”才独立成立，例如明确的一套交付前检查步骤，保存为 Skill，再在下一项任务中调用。需要先敲定具体可见案例；不要把 Skills、Memory、集成、子代理混成同一能力。

官方：https://www.verdent.ai/docs/verdent-manager/core-features/skills

## 建议取舍

先保留图片素材、视频生成、发布上线、定时任务四个清晰主题；远程消息与 Skills 保持候选，不因为之前列过六个就强行制作六集。最终集数和顺序待用户审阅选题后确定。

## 单集制作门槛

1. 一句话说明这集比前七集多讲了什么。
2. 明确输入、可见动作、可用结果；每个动作都有官方功能依据。
3. 先审内容边界和分镜，再做该集动画。
4. 真实 3D 几何、体积、高光、空间手递与连续主体，服务于功能表达。
5. 不把动画修辞冒充产品能力；不靠换文案复制构图。
6. 逐帧检查遮挡、深度冲突和频闪，再检查完整播放。自动检查通过不等于视觉质量通过。
7. 本集审阅后再推进下一集。
